Domain 1 — Architecture (Q1–Q31)

~31% of the real exam. Labs 01–05.

  1. Which statement about virtual warehouses is true?

    • A. Warehouses store micro-partitions for tables
    • B. Warehouses provide compute; table data lives in the storage layer
    • C. Larger warehouses always reduce storage cost
    • D. Cloud Services runs inside your warehouse size
    Answer

    B. WH = compute. Storage holds micro-partitions. A confuses layers; C/D wrong.

  2. Name the three Snowflake architecture layers.

    • A. Database, Schema, Table
    • B. Storage, Query Processing (warehouses), Cloud Services
    • C. Snowsight, SnowSQL, JDBC
    • D. Standard, Enterprise, Business Critical
    Answer

    B. Classic three-layer answer. A = object hierarchy; C = interfaces; D = editions.

  3. Which edition can configure Time Travel up to 90 days?

    • A. Standard only
    • B. Enterprise and above
    • C. Reader accounts only
    • D. Any edition with Fail-safe enabled
    Answer

    B. Standard ~1 day; Enterprise+ for up to 90. Fail-safe ≠ TT length.

  4. Micro-partitions are best described as:

    • A. Fixed 50 MB row groups you manually size
    • B. Contiguous compressed storage units Snowflake manages automatically
    • C. Warehouse cache blocks only
    • D. One partition per table always
    Answer

    B. Auto-managed compressed units. Not WH cache; not one-per-table.

  5. Which interface is the web UI for Snowflake?

    • A. SnowSQL
    • B. Snowsight
    • C. Kafka Connector only
    • D. Fail-safe console
    Answer

    B. Snowsight = web UI; SnowSQL = CLI.

  6. Which is NOT a table type category the exam expects you to distinguish?

    • A. Permanent
    • B. Transient
    • C. Temporary
    • D. Fail-safe table
    Answer

    D. Fail-safe is retention after TT — not a CREATE TABLE type.

  7. Cloud Services layer includes:

    • A. Only virtual warehouse CPU
    • B. Authentication, metadata, query optimization/management
    • C. Only S3/Blob customer buckets you create
    • D. Only Snowpipe billing
    Answer

    B. Cloud Services = control plane (auth, metadata, optimizer).

  8. Business Critical is most associated with which need?

    • A. Free reader accounts only
    • B. Higher security / some advanced failover & compliance features
    • C. Disabling Cloud Services
    • D. Removing Time Travel
    Answer

    B. BC for stricter security and many HA/failover capabilities.

  9. A secure view is used primarily to:

    • A. Force warehouse size to X-Small
    • B. Hide underlying details / prevent some optimization peeking at base objects
    • C. Replace Fail-safe
    • D. Enable Marketplace billing only
    Answer

    B. Secure views protect definition/underlying exposure vs normal views.

  10. Which cloud partners host Snowflake? (exam spirit)

    • A. Only on-prem VMware
    • B. Major public clouds (AWS, Azure, GCP)
    • C. Only AWS Gov alone forever
    • D. Customer laptop Docker only
    Answer

    B. Multi-cloud SaaS on AWS/Azure/GCP.

  11. Cortex / Snowpark / Streamlit in Snowflake sit closest to which blueprint theme?

    • A. Fail-safe administration
    • B. AI / apps / developer platforms (architecture awareness)
    • C. COPY INTO file formats only
    • D. Reader account billing only
    Answer

    B. Domain 1 AI/apps awareness on C03.

  12. Clustering keys help primarily with:

    • A. Making warehouses auto-suspend faster
    • B. Improving pruning / scan efficiency when filters match cluster dimensions
    • C. Granting ACCOUNTADMIN rights
    • D. Creating reader accounts
    Answer

    B. Clustering aids pruning when filters align — not RBAC or suspend.

  13. Separation of storage and compute means DMart can:

    • A. Only scale storage by resizing WH_CORE_XS
    • B. Scale warehouses independently of how much data sits in DMART
    • C. Delete Cloud Services to save money
    • D. Store tables only inside the warehouse local disk forever
    Answer

    B. Elastic compute ≠ storage growth. WH size does not create more storage.

  14. Which statement about editions is most accurate?

    • A. All editions are identical except marketing names
    • B. Higher editions unlock features (e.g., longer TT, MCW, advanced security) at higher cost
    • C. Standard includes Tri-Secret Secure by default always
    • D. VPS is required for every trial account
    Answer

    B. Edition ladder maps features to cost — don't invent features on Standard.

  15. SnowSQL is best described as:

    • A. The web worksheet UI
    • B. A command-line client for Snowflake
    • C. A Marketplace listing type
    • D. A Fail-safe restore tool
    Answer

    B. SnowSQL = CLI; Snowsight = web.

  16. Dynamic Tables primarily help you:

    • A. Replace all roles with ACCOUNTADMIN
    • B. Declare target tables that refresh from a query (pipeline-style)
    • C. Disable micro-partitions
    • D. Create Fail-safe on transient tables
    Answer

    B. Dynamic Tables = declarative refresh pipelines (Domain 1/3 awareness).

  17. Iceberg tables in Snowflake (exam spirit) relate to:

    • A. Only Fail-safe tickets
    • B. Open table format / external catalog themes for data lake tables
    • C. Warehouse auto-suspend only
    • D. Reader account passwords
    Answer

    B. Iceberg = open format / lakehouse-style table awareness on C03.

  18. Which object hierarchy order is correct?

    • A. Column → Table → Schema → Database → Account
    • B. Account → Database → Schema → objects (tables, views…)
    • C. Warehouse → Stage → Edition → Share
    • D. Fail-safe → Time Travel → Clone
    Answer

    B. Account contains databases; databases contain schemas; schemas contain objects.

  19. Materialized views are mainly for:

    • A. Deleting base tables
    • B. Precomputing query results for performance (with maintenance cost)
    • C. Replacing network policies
    • D. Creating editions
    Answer

    B. MVs trade storage/maintenance for faster reads — not security objects.

  20. What burns credits when you SELECT from a large table (typical case)?

    • A. Only storage bytes forever with zero compute
    • B. Virtual warehouse compute (plus any applicable services)
    • C. Only Fail-safe tickets
    • D. Only Marketplace listing fees
    Answer

    B. Queries run on a WH — credits for compute. Storage billed separately.

  21. External tables are best associated with:

    • A. Data remaining in external cloud storage queried via metadata
    • B. Forcing all data into Fail-safe
    • C. Disabling stages
    • D. Replacing RBAC
    Answer

    B. External tables point at files outside Snowflake storage.

  22. Which is true about Snowflake regions?

    • A. One global region only forever
    • B. You choose cloud + region; availability and features can vary by region
    • C. Regions only exist for reader accounts
    • D. Regions store warehouses but never data
    Answer

    B. Cloud provider + region choice matters for latency, compliance, features.

  23. Directory tables help you:

    • A. List/query files on a stage as table rows
    • B. Mask PII columns
    • C. Scale warehouses out
    • D. Create Fail-safe
    Answer

    A. Directory tables = file listing metadata on stages.

  24. Which best describes elastic compute?

    • A. You must buy fixed hardware for 3 years
    • B. Start/stop/resize warehouses on demand without moving data
    • C. Storage shrinks when WH suspends
    • D. Cloud Services disappears when WH suspends
    Answer

    B. Suspend WH → stop compute credits; data remains in storage.

  25. A standard view (non-secure) typically:

    • A. Stores a full physical copy of all base rows always
    • B. Stores a query definition; data comes from underlying objects at runtime
    • C. Is identical to a permanent table
    • D. Requires Business Critical
    Answer

    B. Views are definitions (unless materialized). Secure views add protection.

  26. Which interface family includes JDBC/ODBC drivers?

    • A. Only Snowsight worksheets
    • B. Client drivers/connectors for apps and BI tools
    • C. Only Fail-safe console
    • D. Only ACCOUNT_USAGE
    Answer

    B. Drivers connect applications — Domain 1 interfaces.

  27. Snowflake Notebooks / Streamlit in Snowflake primarily show C03 awareness of:

    • A. Building apps/analytics inside the platform
    • B. Deleting Cloud Services
    • C. Mandatory Fail-safe on temp tables
    • D. COPY ON_ERROR only
    Answer

    A. In-platform apps/notebooks are architecture/AI theme items.

  28. What does auto-suspend on a warehouse do?

    • A. Deletes the database
    • B. Stops the WH after idle time to save credits
    • C. Enables 90-day TT on Standard
    • D. Creates a share
    Answer

    B. Idle WH → suspend → no compute credits until resume.

  29. Which statement about multi-cluster warehouses is most accurate?

    • A. They always reduce storage cost
    • B. They add clusters to handle concurrency (scale out)
    • C. They replace Time Travel
    • D. They only exist on Standard trial
    Answer

    B. MCW = concurrency; often Enterprise+ feature theme.

  30. Compressed micro-partition storage means:

    • A. You manually gzip every INSERT
    • B. Snowflake stores data in compressed columnar micro-partitions
    • C. Warehouses hold uncompressed copies of all tables always
    • D. Fail-safe compresses roles
    Answer

    B. Storage layer compresses data in micro-partitions automatically.

  31. Which is the best one-liner for Cortex on the exam?

    • A. Cortex deletes warehouses
    • B. Cortex = Snowflake AI functions/services you call from SQL / platform (awareness)
    • C. Cortex replaces Secure Data Sharing
    • D. Cortex is Fail-safe for VARIANT
    Answer

    B. Know Cortex as AI capability awareness — not a storage layer.

EXAM TIP
Layer test. If an option says the warehouse “stores” tables — eliminate it. Storage · Compute · Cloud Services.

Domain 2 — Account management & governance (Q32–Q51)

~20% of the real exam. Labs 06–09.

  1. RBAC in Snowflake is primarily about:

    • A. Assigning privileges to roles, then roles to users
    • B. Storing passwords in tables
    • C. Cloning warehouses
    • D. Fail-safe tickets
    Answer

    A. Privileges → roles → users.

  2. Dynamic data masking typically:

    • A. Deletes columns permanently
    • B. Transforms column values at query time based on role/policy
    • C. Doubles warehouse size
    • D. Enables replication
    Answer

    B. Masking policies alter what roles see without rewriting stored data.

  3. Row access policies control:

    • A. Which rows a role can see
    • B. Warehouse auto-resume only
    • C. Fail-safe duration
    • D. Stage file format
    Answer

    A. RAP = rows; masking = column values.

  4. Resource Monitors are used to:

    • A. Mask emails
    • B. Track/limit credit usage and notify or suspend
    • C. Create shares
    • D. Replace Time Travel
    Answer

    B. Cost governance via credit quotas/actions.

  5. ACCOUNT_USAGE views are useful for:

    • A. Live millisecond operational locks only
    • B. Historical monitoring of queries, logins, usage (with latency)
    • C. Replacing INFORMATION_SCHEMA entirely for all DDL
    • D. Fail-safe restores
    Answer

    B. Account-level history; expect latency vs INFORMATION_SCHEMA.

  6. Network policies primarily restrict:

    • A. Which IP/CIDR ranges can authenticate
    • B. Micro-partition size
    • C. Marketplace prices
    • D. Clone privileges only
    Answer

    A. Network policies allow/block client IPs.

  7. Object tagging helps mainly with:

    • A. Governance classification / tracking sensitive data
    • B. Speeding COPY INTO always
    • C. Disabling Cloud Services
    • D. Creating Fail-safe
    Answer

    A. Tags for governance/classification workflows.

  8. MFA / SSO / key-pair auth are examples of:

    • A. Storage layer features
    • B. Authentication / access security controls
    • C. Clustering keys
    • D. Transient table options
    Answer

    B. Domain 2 authentication themes.

  9. What should you run when proving a functional role cannot see vault data in Snowsight?

    • A. USE ROLE FR_ANALYST; only
    • B. USE ROLE FR_ANALYST; USE SECONDARY ROLES NONE;
    • C. DROP ROLE ACCOUNTADMIN;
    • D. ALTER WAREHOUSE SUSPEND;
    Answer

    B. Secondary roles often stay active — NONE for honest privilege proofs.

  10. Ownership of an object typically means:

    • A. You alone can query every database
    • B. The owning role controls the object and can grant privileges on it
    • C. Fail-safe is disabled
    • D. The warehouse must be Multi-cluster
    Answer

    B. Owner role governs grants/DDL on that object.

  11. Trust Center (exam awareness) relates to:

    • A. Security posture / monitoring themes for the account
    • B. Clustering key syntax only
    • C. COPY ON_ERROR defaults
    • D. Marketplace refunds
    Answer

    A. Trust Center = security assessment/monitoring awareness.

  12. Which statement about roles is true?

    • A. Users should usually own all privileges directly, never roles
    • B. Roles are the containers for privileges; users activate roles
    • C. ACCOUNTADMIN is required for SELECT on every table
    • D. Roles store micro-partitions
    Answer

    B. Activate a role; privileges hang on roles.

  13. Column-level security via masking vs row filter:

    • A. Same SQL object type always
    • B. Masking transforms columns; RAP filters rows
    • C. Both only work on transient tables
    • D. Both replace network policies
    Answer

    B. Memorize: columns vs rows.

  14. Classification / sensitive data features help you:

    • A. Automatically find and label sensitive columns (governance)
    • B. Resize warehouses
    • C. Create Fail-safe
    • D. Disable shares
    Answer

    A. Data classification supports governance tagging workflows.

  15. Lineage (exam awareness) helps you understand:

    • A. How data flows between objects / dependencies
    • B. Only warehouse suspend times
    • C. Only Fail-safe tickets
    • D. Only file format CSV headers
    Answer

    A. Lineage = dependency/flow awareness.

  16. OAuth for Snowflake clients is primarily about:

    • A. Delegated authentication for applications
    • B. Compressing micro-partitions
    • C. Creating Dynamic Tables
    • D. Fail-safe restore
    Answer

    A. OAuth = app auth pattern alongside SSO/key-pair/MFA.

  17. Which is a FinOps best practice for DMart?

    • A. Leave WH_CORE_M running 24/7 with no monitor
    • B. Attach resource monitors and use auto-suspend on warehouses
    • C. Grant ACCOUNTADMIN to every analyst
    • D. Disable ACCOUNT_USAGE
    Answer

    B. Monitors + auto-suspend = credit control.

  18. INFORMATION_SCHEMA vs ACCOUNT_USAGE — pick the true statement:

    • A. They are identical with zero latency differences
    • B. INFORMATION_SCHEMA is more real-time for current DB; ACCOUNT_USAGE is account history with latency
    • C. ACCOUNT_USAGE replaces all stages
    • D. INFORMATION_SCHEMA deletes Fail-safe

  19. Least privilege for DMart analysts usually means:

    • A. Everyone is ACCOUNTADMIN
    • B. Functional roles with only needed object grants (not god-mode)
    • C. No roles at all
    • D. Only PUBLIC role forever
    Answer

    B. Grant minimum needed via roles.

  20. Sam asks: can masking hide SSN while RAP limits store_id rows together?

    • A. No — only one policy type per account
    • B. Yes — column masking and row access can work together
    • C. Only on Standard edition
    • D. Only if the table is temporary
    Answer

    B. Policies compose: columns + rows.

Domain 3 — Loading, unloading & connectivity (Q52–Q69)

~18% of the real exam. Labs 10–12.

  1. COPY INTO a table from a stage is best described as:

    • A. Continuous auto-ingest only
    • B. Batch load you run (or schedule) from files
    • C. Fail-safe restore
    • D. Zero-copy clone
    Answer

    B. COPY = batch. Snowpipe = continuous/auto.

  2. Snowpipe is designed for:

    • A. Continuous/near-continuous loading as files arrive
    • B. Replacing all warehouses
    • C. Manual UNDROP only
    • D. Marketplace billing only
    Answer

    A. Pipe automation vs batch COPY.

  3. A named stage can reference:

    • A. Only local laptop RAM
    • B. Internal Snowflake stages or external cloud storage locations
    • C. Fail-safe only
    • D. Reader accounts only
    Answer

    B. Internal/external stages for load/unload.

  4. Streams track:

    • A. Warehouse suspend events only
    • B. Change data (CDC-style) on a table for downstream processing
    • C. Marketplace listings
    • D. Fail-safe tickets
    Answer

    B. Table streams = change tracking.

  5. Tasks are used to:

    • A. Schedule SQL / pipeline steps in Snowflake
    • B. Mask columns
    • C. Create editions
    • D. Replace micro-partitions manually
    Answer

    A. Tasks schedule work (often with streams).

  6. File format objects define:

    • A. CSV/JSON/Parquet parse options for load/unload
    • B. Role hierarchies
    • C. Fail-safe windows
    • D. Warehouse sizes
    Answer

    A. FILE FORMAT = structure/options for files.

  7. Storage integrations primarily:

    • A. Secure trust between Snowflake and cloud storage without embedding long-lived keys in every stage
    • B. Delete ACCOUNT_USAGE
    • C. Replace RBAC
    • D. Create reader accounts
    Answer

    A. Integrations for secure external storage access.

  8. Snowpipe Streaming (exam spirit) is closest to:

    • A. Row-oriented continuous ingest via SDK/API themes
    • B. Only weekly COPY of CSV
    • C. Fail-safe restore
    • D. Secure view definition
    Answer

    A. Streaming ≠ file-batch COPY.

  9. ON_ERROR = ABORT_STATEMENT on COPY typically means:

    • A. Ignore all errors forever
    • B. Stop the load when errors hit the abort behavior
    • C. Create a share
    • D. Enable MCW
    Answer

    B. ABORT stops; CONTINUE can skip bad data per settings — know the difference.

  10. Unloading data with COPY INTO a stage:

    • A. Writes query results out to files on a stage
    • B. Deletes Time Travel
    • C. Creates Fail-safe
    • D. Grants ACCOUNTADMIN
    Answer

    A. Unload = export files via COPY INTO location.

  11. Kafka Connector themes on C03 map to:

    • A. Landing streaming/event data into Snowflake
    • B. Only UNDROP
    • C. Only masking policies
    • D. Only resource monitors
    Answer

    A. Connectors/integrations for pipelines.

  12. User stage vs named stage — true statement:

    • A. There is no user stage
    • B. Users have personal stages; named stages are shared schema objects
    • C. Named stages only exist in Fail-safe
    • D. User stages replace warehouses
    Answer

    B. Know stage types: user/table/named; internal vs external.

  13. Dynamic Tables vs Streams+Tasks (exam spirit):

    • A. Identical syntax always
    • B. Different pipeline styles — DT declarative refresh vs stream/task CDC patterns
    • C. Both replace COPY
    • D. Both require VPS
    Answer

    B. Know both automation vocabularies.

  14. External stages typically point to:

    • A. Cloud object storage buckets/containers
    • B. Only local /tmp on the WH
    • C. Fail-safe only
    • D. Cortex models only
    Answer

    A. External = cloud storage location.

  15. VALIDATION_MODE on COPY helps you:

    • A. Test/parse without (or with limited) loading to catch errors
    • B. Mask columns
    • C. Scale out warehouses
    • D. Create shares
    Answer

    A. Validate files before committing load.

  16. API integrations (exam awareness) support:

    • A. Secure calls to external APIs from Snowflake features
    • B. Deleting micro-partitions
    • C. Replacing editions
    • D. Fail-safe tickets
    Answer

    A. Integrations family includes API/storage/notification themes.

  17. Which load pattern fits nightly DMart order files you control?

    • A. Always Snowpipe Streaming SDK for a single daily CSV
    • B. Batch COPY INTO from a stage on a schedule (or task)
    • C. Only Fail-safe restore
    • D. Only zero-copy clone
    Answer

    B. Batch files → COPY; continuous files → pipe.

  18. FORCE => TRUE on COPY (exam spirit) can:

    • A. Reload files even if already loaded (careful with duplicates)
    • B. Enable 90-day TT on Standard
    • C. Grant SSO
    • D. Create MCW
    Answer

    A. FORCE reloads; know duplicate risk.

EXAM TIP
Load triad. COPY = batch · Snowpipe = continuous files · Streaming = rows/SDK. Don’t mix them.

Domain 4 — Performance, querying & transformation (Q70–Q90)

~21% of the real exam. Labs 13–15.

  1. Result cache returns prior results when:

    • A. Any similar English question is asked
    • B. Eligible identical query context and underlying data unchanged (rules apply)
    • C. Always after 1 second
    • D. Only on transient tables
    Answer

    B. Result cache is conditional — not magic fuzzy match.

  2. Micro-partition pruning helps by:

    • A. Skipping irrelevant micro-partitions based on metadata/filters
    • B. Deleting Cloud Services
    • C. Granting roles
    • D. Creating shares
    Answer

    A. Pruning = scan less → faster/cheaper.

  3. Scale up vs scale out — correct pairing:

    • A. Up = more clusters for concurrency; Out = larger size for harder queries
    • B. Up = larger warehouse size for heavier queries; Out = more clusters for concurrency
    • C. Both always mean Fail-safe
    • D. Both only change storage
    Answer

    B. Memorize: size vs clusters.

  4. Auto-suspend exists mainly to:

    • A. Delete databases nightly
    • B. Stop idle compute credits
    • C. Enable Marketplace
    • D. Create RAP
    Answer

    B. Idle WH should not burn credits.

  5. Query Profile is used to:

    • A. Inspect operators, bytes scanned, spills, pruning clues
    • B. Mask SSN
    • C. Create editions
    • D. Book Pearson
    Answer

    A. Profile before guessing scale-up.

  6. VARIANT columns store:

    • A. Only integers
    • B. Semi-structured data (JSON-like) with path access
    • C. Only encrypted roles
    • D. Only warehouse configs
    Answer

    B. VARIANT = semi-structured type.

  7. QUALIFY is used to:

    • A. Filter results of window functions
    • B. Create stages
    • C. Set network policies
    • D. Enable Fail-safe
    Answer

    A. QUALIFY = WHERE for window outputs.

  8. When a query spills to local/remote storage, a likely response is:

    • A. Ignore Profile forever
    • B. Consider larger WH / reduce memory pressure / rewrite query
    • C. Drop ACCOUNT_USAGE
    • D. Disable pruning
    Answer

    B. Spill ⇒ memory pressure — Profile + size/rewrite.

  9. Query Acceleration Service (QAS) awareness:

    • A. Can help eligible queries with extra serverless compute
    • B. Replaces all warehouses permanently
    • C. Is Fail-safe
    • D. Is a table type
    Answer

    A. QAS = optional acceleration — know it exists.

  10. Metadata cache / warehouse cache themes:

    • A. All caches are identical to Fail-safe
    • B. Different caches (result, WH local, metadata) speed repeats under rules
    • C. Caches store roles
    • D. Caches require VPS
    Answer

    B. Know multiple cache layers — not one blob.

  11. MERGE is primarily for:

    • A. Upsert-style insert/update/delete from a source
    • B. Creating shares
    • C. Setting SSO
    • D. Fail-safe tickets
    Answer

    A. MERGE = conditional DML patterns.

  12. FLATTEN helps you:

    • A. Unnest nested VARIANT/array structures into rows
    • B. Scale warehouses
    • C. Create monitors
    • D. Enable MFA
    Answer

    A. FLATTEN for semi-structured unnesting.

  13. PIVOT in SQL is for:

    • A. Rotating row values into columns for reporting shapes
    • B. Cloning accounts
    • C. Network allow lists
    • D. Snowpipe billing
    Answer

    A. PIVOT = reshape results.

  14. UDFs / stored procedures (exam spirit):

    • A. Extend logic in Snowflake (SQL/JS/Python themes via Snowpark)
    • B. Replace storage layer
    • C. Disable Cloud Services
    • D. Create Fail-safe
    Answer

    A. Programmability awareness.

  15. Selectivity of filters matters because:

    • A. Highly selective filters improve pruning/scan efficiency
    • B. Filters always disable result cache forever
    • C. Filters create editions
    • D. Filters grant roles
    Answer

    A. Good filters → better pruning.

  16. Concurrency slowdown with many users often points to:

    • A. Need scale-out / multi-cluster rather than only bigger single cluster
    • B. Need to delete storage
    • C. Need Fail-safe
    • D. Need to remove stages
    Answer

    A. Queueing ⇒ scale out / MCW.

  17. Warehouse local disk cache helps:

    • A. Repeated scans of data already cached on that WH
    • B. Permanent Fail-safe forever
    • C. SSO login
    • D. Marketplace search
    Answer

    A. Warm WH can avoid re-reading remote storage — still not 'WH stores tables'.

  18. Which first step when Kai says 'make it faster'?

    • A. Immediately XL the warehouse with no evidence
    • B. Check Query Profile: pruning, bytes, spill, queues
    • C. Drop the table
    • D. Disable auto-suspend forever

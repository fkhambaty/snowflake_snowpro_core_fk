Architecture & objects

Name the three Snowflake layers.

Storage (micro-partitions) · Compute (virtual warehouses) · Cloud Services (auth, metadata, optimizer).

Does a warehouse store table data?

No. WH = compute kitchen. Tables live in the storage pantry.

Standard vs Enterprise — Time Travel length?

Standard typically 1 day. Up to 90 days needs Enterprise+.

Business Critical is mainly about…?

Security / advanced HA & compliance themes — don’t pick BC just for Time Travel.

What are micro-partitions?

Auto-managed compressed storage units Snowflake creates — you don’t hand-size 50 MB blocks.

Clustering keys help with what?

Pruning / scan efficiency when filters match cluster dimensions.

Permanent vs transient vs temporary — Fail-safe?

Permanent: TT + Fail-safe. Transient/temp: no Fail-safe (limited TT).

Snowsight vs SnowSQL?

Snowsight = web UI. SnowSQL = CLI client.

Cortex one-liner?

Snowflake AI functions/services you call from SQL / the platform (awareness on C03) — does not replace warehouses.

Secure view vs normal view?

Secure view protects definition / underlying exposure; normal views can leak more to the optimizer/users.

Object hierarchy order?

Account → Database → Schema → objects (tables, views, stages…).

Dynamic Tables one-liner?

Declare a target table that refreshes from a query (pipeline-style), not a Fail-safe feature.

Account, security & cost

RBAC in one line?

Privileges → roles → users. Activate a role; don’t hang privileges only on users.

Masking vs RAP?

Masking = column values at query time. RAP = which rows you see.

Why USE SECONDARY ROLES NONE?

Snowsight keeps secondary roles active. Privilege proofs need NONE or vault “fails open.”

Resource Monitors do what?

Track/limit credits; notify or suspend when quotas hit.

ACCOUNT_USAGE vs INFORMATION_SCHEMA?

ACCOUNT_USAGE = account history (latency OK). INFORMATION_SCHEMA ≈ more current DB metadata.

Network policies restrict…?

IP / CIDR ranges that can authenticate.

MFA / SSO / key-pair are…?

Authentication controls (Domain 2 security).

Object tags help with…?

Governance / classification tracking of sensitive data.

Least privilege means…?

Functional roles with only needed grants — not everyone ACCOUNTADMIN.

Ownership of an object means…?

Owning role controls the object and can grant privileges on it.

Trust Center (awareness)?

Account security posture / monitoring themes — not a clustering feature.

Can masking + RAP work together?

Yes — columns and rows are different policy axes.

Loading & pipelines

COPY vs Snowpipe vs Streaming?

COPY = batch you run. Snowpipe = continuous files. Streaming = rows/SDK continuous ingest.

What does a stage hold?

A file location — internal Snowflake stage or external cloud storage.

FILE FORMAT objects define…?

Parse options for CSV / JSON / Parquet (etc.) on load/unload.

ON_ERROR = ABORT_STATEMENT means…?

Load stops when error threshold/behavior triggers — not “ignore quality forever.”

Streams track…?

Change data (CDC-style) on a table for downstream processing.

Tasks are for…?

Scheduling SQL / pipeline steps (often with streams).

Storage integration purpose?

Trusted access to cloud storage without stuffing keys into every stage.

Unload pattern?

COPY INTO @stage writes query results out to files.

VALIDATION_MODE on COPY?

Test/parse files to catch errors before (or without) full load commit.

Nightly DMart CSV batch — which tool?

Usually COPY INTO (scheduled). Pipe if files arrive continuously.

FORCE => TRUE on COPY risk?

Can reload already-loaded files → duplicate rows if you’re not careful.

Kafka Connector theme?

Land streaming/event data into Snowflake (connector awareness).

Performance & SQL

Scale up vs scale out?

Up = larger size (harder queries). Out = more clusters (concurrency).

First step when a query is “slow”?

Query Profile: pruning, bytes scanned, spill, queues — then decide size vs MCW.

Result cache returns when…?

Eligible same query context and underlying data unchanged — not fuzzy English match.

Pruning does what?

Skips irrelevant micro-partitions using metadata + filters.

Auto-suspend exists to…?

Stop idle compute credits when the WH isn’t working.

VARIANT is…?

A semi-structured type (JSON-like) with path access — not plain VARCHAR.

QUALIFY filters…?

Results of window functions (WHERE can’t see them the same way).

FLATTEN helps with…?

Unnesting nested VARIANT / arrays into rows.

Spill in Profile suggests…?

Memory pressure — consider larger WH and/or rewrite; don’t ignore.

Multi-cluster warehouse fixes…?

Mostly concurrency / queuing — not a substitute for pruning fixes.

MERGE is for…?

Upsert-style insert/update/delete from a source.

QAS one-liner?

Query Acceleration Service — optional serverless boost for eligible queries.

Collaboration, TT & DR

Time Travel vs Fail-safe?

TT = you recover with SQL. Fail-safe = Support only, after TT (~7d permanent).

Share vs clone vs replicate?

Share = live access. Clone = zero-copy twin in-account. Replicate = DR across region/account.

Zero-copy clone storage?

Shares micro-partitions until divergence — not an instant full byte copy.

UNDROP works within…?

Time Travel retention for dropped tables/schemas/DBs.

AT | BEFORE clauses?

Point-in-time Time Travel reads as of timestamp/statement.

Reader accounts when…?

Consumer needs shared data but no Snowflake account of their own.

Secure share ≠ CSV email?

Share = live query access; consumer typically pays their compute.

Marketplace one-liner?

Discover/share datasets & services in Snowflake’s marketplace ecosystem.

Native Apps awareness?

Distribute apps that run in consumer accounts with controlled access themes.

Clean Rooms awareness?

Collaborate on sensitive data with controlled overlap/analysis — not a public PII dump.

Transient has Fail-safe?

No. Classic trap — transient/temp skip Fail-safe.

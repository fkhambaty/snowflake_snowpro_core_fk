# Exam day playbook — SnowPro Core COF-C03

## Night before (30 minutes)

Say out loud:

1. **Three layers:** Storage · Compute (WH) · Cloud Services  
2. **Editions:** Standard (1-day TT) · Enterprise (90-day TT, MCW…) · Business Critical (security) · VPS  
3. **TT ≠ Fail-safe** · Transient has **no** Fail-safe  
4. **Masking = columns · RAP = rows**  
5. **COPY (WH) vs Snowpipe (serverless) vs Streaming (rows/SDK)**  
6. **Scale up = harder queries · Scale out = concurrency**  
7. **Share = live · Clone = zero-copy twin · Replicate = DR**

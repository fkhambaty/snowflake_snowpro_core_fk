Before Step 1

Kai: “Can I share from the same account to myself?”

1 Curated view in SHARE_DEMO

What this does: Builds a safe product catalog view — nothing from CUSTOMERS.

SQL · share-safe view
USE ROLE ROLE_CORE_LAB_ADMIN;
USE WAREHOUSE WH_CORE_XS;
USE DATABASE ALPINE_RETAIL;
USE SCHEMA SHARE_DEMO;

CREATE OR REPLACE VIEW V_PRODUCT_CATALOG AS
SELECT 1 AS PRODUCT_ID, 'Trail Jacket' AS PRODUCT_NAME, 129.00 AS LIST_PRICE
UNION ALL SELECT 2, 'Alpine Cap', 24.00
UNION ALL SELECT 3, 'Summit Pack', 89.00;
✓ Three product rows; no PII columns

Before Step 2

Riley: “Why USAGE before SELECT?”

2 CREATE SHARE + grants

What this does: Creates the share container and grants the path + SELECT into it.

SQL · share + grants
CREATE SHARE IF NOT EXISTS ALPINE_PRODUCT_SHARE
  COMMENT = 'Alpine Retail catalog share for Core lab';

GRANT USAGE ON DATABASE ALPINE_RETAIL
  TO SHARE ALPINE_PRODUCT_SHARE;
GRANT USAGE ON SCHEMA ALPINE_RETAIL.SHARE_DEMO
  TO SHARE ALPINE_PRODUCT_SHARE;
GRANT SELECT ON VIEW ALPINE_RETAIL.SHARE_DEMO.V_PRODUCT_CATALOG
  TO SHARE ALPINE_PRODUCT_SHARE;
✓ Grants succeed (needs CREATE SHARE from Lab 00 bootstrap)

3 Prove with SHOW + remember ADD ACCOUNTS

What this does: Lists the share and its grants. Consumer delivery is a commented next step.

SQL · SHOW SHARES
SHOW SHARES LIKE 'ALPINE_PRODUCT_SHARE';
SHOW GRANTS TO SHARE ALPINE_PRODUCT_SHARE;

Exam presses further — say these out loud

Q1. Is a share a copy of the data?

Say: No — secure sharing is live access to provider-stored data (via granted objects). It is not a nightly export. Revoking or removing an account cuts access without chasing CSV copies.

Q2. Who pays compute when the consumer queries?

Say: Typically the consumer’s virtual warehouse credits. The provider pays for storing the shared data. (Don’t say the provider’s WH runs the consumer’s SELECT.)

Q3. What is a reader account?

Say: A provider-managed Snowflake account so a partner can consume shared data without owning a full paid Snowflake account. Still a separate account identity for sharing.

Q4. What problem do Data Clean Rooms solve?

Say: Multiple parties want joint analysis without freely exposing raw customer-level rows to each other — controlled, privacy-preserving collaboration (exam awareness, not deep admin).

Q5. Listing vs direct share?

Say: Direct share: you ADD known accounts. Marketplace listing: discoverable/commercial offering in the Marketplace. Same collaboration family; different discovery and commercial path.
